Use of AI Declaration:

I used ChatGPT as a tool during the development of this Java project.

AI was used to:

Help debug Java errors and explain compiler messages (like how and why some errors have occurred. For example, I had encountered a syntax error and I wanted to know exactly why it was occurring), clarify concepts such as inheritance and subclasses (this I used to understand how I could use City Engine’s features such as extending DynamicBody in order to make subclasses), give me guidance on implementing keyboard controls (this was used especially to understand how to use movement in the game as I used key listeners), and collision handling in CityEngine (used for many things such as my double jump feature and the collision with the in-game bomb), help with the menu system with ideas such as the settings (where options such as sound and music handling are included), and AI was used to learn more deeply how I could save a leaderboard of attempts of the game.
The AI was not used to generate the entire project. Any code given to me by ChatGPT was used to learn how I could develop the game code and the class structure. I tested all functionality myself to ensure it runs correctly and meets the project specification (Milestone 1 and Milestone 2).
I did use AI to give me inspiration for characters and background options, but they were used to adapt current sprites and backgrounds for my game.
